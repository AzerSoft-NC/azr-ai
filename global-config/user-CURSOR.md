# User-Level Cursor Config (pointer)

Cursor loads the router from the always-on rule installed by [install-skills.sh](../install-skills.sh):

**[rules/skill-router.mdc](../rules/skill-router.mdc)** → `~/.cursor/rules/skill-router.mdc`

Do **not** paste a duplicate router into Cursor User Rules — edits belong in the catalog rule; re-run the installer after changes.

Optional: adapt project-specific notes into a repo `AGENTS.md`. Personal preferences can stay in User Rules as short bullets only (privacy, git habits) — not a second skill map.

Skills install to `~/.cursor/skills/<name>/` via the same script (catalog + pinned vendors). See [README.md](../README.md).
