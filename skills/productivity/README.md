# Productivity skills

General workflow tools. Install via [../../install-skills.sh](../../install-skills.sh).

## User-invoked

- **[handoff](./handoff/SKILL.md)** — Compact conversation for another agent.

## Model-invoked

- **[caveman](./caveman/SKILL.md)** — Token-efficient replies (lite / full / ultra / wenyan-*).
- **[grill-me](./grill-me/SKILL.md)** — Domain model, glossary, ADRs, architecture forks; design heuristics included.
- **[less-trouble](./less-trouble/SKILL.md)** — Document resolved env issues into `docs/troubleshoot/TROUBLESHOOT.md`; holds the human-in-the-loop reproduction template.
- **[teach-me](./teach-me/SKILL.md)** — Reverse-engineer undocumented code into `context/rg/`.
- **[map-architecture](./map-architecture/SKILL.md)** — Curated workspace graph at `context/architecture-graph.json`.

Skill authoring is vendored from superpowers as `writing-skills`.
