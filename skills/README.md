# Skills

Portable skill definitions live here, grouped by category. Install with [../install-skills.sh](../install-skills.sh) (copies to `~/.cursor/skills/<name>/`; categories `engineering`, `productivity`, `misc` only).

This catalog holds only what has no upstream equivalent. Debugging, TDD, skill authoring, planning and code review come from vendored [superpowers](https://github.com/obra/superpowers) — see [../README.md](../README.md).
